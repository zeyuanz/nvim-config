# Personal PC setup

1. Install related plugins to enable full functions

```neovim, fd, tree-sitter, n, astyle, ripgrep```
2. Add paths to .bashrc

E.g.

'''
export PATH=/home/zeyuanz/plugins/neovim/bin:$PATH
export PATH=/home/zeyuanz/plugins/fd:$PATH
export PATH=/home/zeyuanz/plugins/tree-sitter:$PATH
export PATH=/home/zeyuanz/plugins/n/bin:$PATH
export PATH=/home/zeyuanz/plugins/astyle:$PATH
export PATH=/home/zeyuanz/plugins/ripgrep/:$PATH
'''
